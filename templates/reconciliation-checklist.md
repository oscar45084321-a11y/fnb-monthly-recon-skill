# 月结三线对账检查清单

## A. 对账范围

- [ ] 明确门店和营业主体
- [ ] 明确起止日期、时区和营业日定义
- [ ] 明确 POS 使用下单时间还是支付完成时间
- [ ] 明确银行/支付通道使用交易日还是到账日
- [ ] 确认 T+1、节假日延迟和跨月到账
- [ ] 明确团购使用核销时间还是结算时间

## B. 数据导出

- [ ] POS 订单明细
- [ ] POS 退款、撤单、冲正明细
- [ ] 支付通道或银行流水
- [ ] 支付通道手续费和结算账单
- [ ] 团购核销明细
- [ ] 团购结算账单和平台费
- [ ] 现金盘点表和交班记录
- [ ] 固定成本和变动成本凭证

## C. 计算与匹配

- [ ] 三方字段名称和金额口径已映射
- [ ] 订单号、商户单号、券码关联规则已确认
- [ ] 退款按发生日或结算日的处理规则已确认
- [ ] 已区分订单金额、核销金额、结算金额、净到账
- [ ] 已处理合并入账、拆分入账和跨日订单
- [ ] 已按支付方式汇总
- [ ] 已逐笔标记未匹配记录
- [ ] 差异金额能回溯到原始记录

## D. 差异处理

- [ ] POS 有单、支付通道无到账
- [ ] 支付通道有到账、POS 无单
- [ ] 团购已核销、POS 无记录
- [ ] POS 有团购单、团购未核销
- [ ] 金额一致但笔数不一致
- [ ] 退款或冲正未同步
- [ ] 手续费率与合同/账单一致
- [ ] 每项差异都有原因、证据、责任人和截止日期

## E. 成本与利润

- [ ] 固定成本已完整登记
- [ ] 变动成本已完整登记
- [ ] 工资、提成、平台费没有重复计算
- [ ] 毛利润公式和营业额口径一致
- [ ] 净利润已扣除约定固定成本
- [ ] 税费、待付款和应收款已单独标注
- [ ] 分红前已预留现金流和储备金
- [ ] 分配比例与合伙协议一致

## F. 归档与安全

- [ ] 报告经过第二人复核
- [ ] 原始文件只读归档
- [ ] 差异附件已编号并可追溯
- [ ] 公开分享前已删除真实数据
- [ ] 已删除密码、密钥、完整账号和个人信息
- [ ] 报告访问权限仅授予必要人员
