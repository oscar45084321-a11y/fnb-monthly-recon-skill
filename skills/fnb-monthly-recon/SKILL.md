# 小型餐饮门店月结三线对账

## 一、核心原则

三线对账的核心是三方统一：POS 系统的交易记录、支付通道的银行到账流水、团购平台的核销记录，必须在完全相同的日期范围内逐笔比对。任何一条线单独看都对，但三条线交叉比对才能发现：漏单、错单、退款未入账、团购未核销、支付通道延迟到账等问题。

> 铁律：宁可对账多花两小时，也不放过一笔差异。账目准确优先于利润分配。

## 二、适用场景

- 单店或小连锁餐饮门店的月度财务结算
- POS 系统（客如云、银豹、美团收银等）+ 第三方支付通道（合利宝、收钱吧、微信支付直连等）+ 团购平台（美团、抖音团购等）的典型配置
- 月结周期通常为自然月或自定义 28 日周期

## 三、前置准备

### 3.1 确认对账周期

对账前必须确认三方使用完全一致的日期窗口：

1. 确认 POS 系统的报表日期范围（注意 POS 按下单时间还是支付时间统计）
2. 确认支付通道银行流水的到账日期（T+1 到账的，日期窗口需整体后移一天）
3. 确认团购平台的核销记录日期范围

> 常见坑：支付通道 T+1 到账，当日营业额次日才进账。对账时银行流水窗口要比 POS 窗口整体后移一天，或统一按“交易发生日”口径拉取银行流水明细（而非到账日）。

### 3.2 准备数据源

对账需要拉取以下三份数据：

| 线路 | 数据源 | 关键字段 |
|:--|:--|:--|
| 第一线 | POS 系统月度交易明细 | 交易时间、订单号、金额、支付方式、退款记录 |
| 第二线 | 支付通道银行流水 | 到账时间、交易金额、交易类型（微信/支付宝/云闪付/现金）、商户单号 |
| 第三线 | 团购平台核销明细 | 核销时间、套餐名称、核销金额、核销状态 |

## 四、对账工作流

### 4.1 第一步：汇总三方总额

分别统计三方在统一日期窗口内的总额：

1. POS 系统汇总：当日/当月营业额合计，按支付方式分项列示
2. 银行流水汇总：到账总额，按交易类型分项列示
3. 团购平台汇总：已核销套餐总额

### 4.2 第二步：三方交叉核对

按以下逻辑逐层比对：

1. 总额核对：三方总额应一致或有可解释差异。若总额一致，进入逐笔核对；若不一致，进入差异排查。
2. 分项核对：按支付方式（微信/支付宝/云闪付/现金）逐项比对 POS 与银行流水。
3. 团购核对：团购核销金额应与 POS 中对应订单金额一致；核对核销笔数是否与 POS 记录匹配。

### 4.3 第三步：差异排查

常见的差异类型及排查方法：

| 差异类型 | 原因 | 排查方法 |
|:--|:--|:--|
| 金额一致，笔数不一致 | 存在合并入账或拆分入账 | 按商户单号逐笔匹配，确认合并/拆分对应关系 |
| POS 有单，银行无到账 | 支付通道延迟、退款未到账、网络异常 | 核对退款记录，隔日复查银行流水 |
| 银行有到账，POS 无单 | 退款冲正、测试交易、跨日订单 | 核对 POS 退款记录与冲正记录 |
| 团购已核销，POS 无记录 | 核销未同步、手动核销漏录 | 登录团购后台导出核销明细逐笔比对 |
| POS 有团购订单，团购未核销 | 系统延迟、核销状态未更新 | 隔日复查团购平台核销状态 |

### 4.4 第四步：成本与利润核算

对账无误后，按以下顺序计算利润：

1. 固定成本：房租 + 水电物业 + 人员工资（含提成） + 其他固定支出
2. 变动成本：食材采购 + 损耗 + 平台抽成 + 佣金
3. 毛利润 = 营业额 - 变动成本
4. 净利润 = 毛利润 - 固定成本
5. 盈亏线 = 固定成本 / 30（日均）或 固定成本（月均）

### 4.5 第五步：利润分配

按以下优先顺序分配利润（具体比例以门店合伙协议为准）：

1. 扣除固定开支
2. 返还投资本金（若有借款/垫资）
3. 计提公账储备金（建议预留 1~2 个月固定成本作为流动资金）
4. 余款按合伙比例分红

## 五、月结报告输出

对账完成后，生成月结报告，包含以下内容：

1. 对账周期与三方总额对照表
2. 差异排查记录（如有）
3. 成本明细表（固定 + 变动）
4. 利润核算表
5. 利润分配方案
6. 遗留问题与下月关注事项

## 六、注意事项

- 现金收入无银行流水佐证，须以 POS 现金记录 + 实际现金盘点为准
- 团购套餐核销金额与实际到账金额可能存在平台抽成差额，对账时须区分“核销金额”与“结算到账金额”
- 每月核对一次支付通道手续费率是否变动
- 员工提成若按营业额比例计算，须以对账后的准确营业额为准，而非 POS 首屏显示的粗略值
- 对账数据涉及商业机密，报告生成后注意保管，不外传不外发
